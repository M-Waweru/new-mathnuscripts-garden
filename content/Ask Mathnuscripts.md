# Ask Mathnuscripts

Ask questions about the ideas, essays, research, and connections in the Mathnuscripts.

> [!info] Pilot status
> The embedded Ask interface is now available across the garden. The grounded retrieval index is being prepared for the next pilot slice. ChatGPT sign-in will be added behind the same interface; it will use the signed-in user's own ChatGPT/Codex allowance.

## How it will work

1. Open **Ask** from any note, or use the floating button.
2. Ask about the note you are reading or highlight a passage first.
3. Mathnuscripts retrieves relevant passages from the published garden.
4. The assistant answers with links back to the source notes.
5. Continue the exploration with follow-up questions.

## Try these questions

- What does Mathnuscripts mean by a digital mind?
- Which notes should I read after this one?
- How are the garden, reading paths, and publishing connected?
- Challenge the central claim in this note.
- Find the different ways this idea appears across the garden.

## About the pilot

The first release is deliberately limited to public Mathnuscripts content and text questions. It will use a small, rate-limited retrieval path before we consider semantic embeddings, saved conversations, private notes, or other model providers.

Connecting ChatGPT will require informed consent. Questions and relevant Mathnuscripts passages will pass through the application and may consume the user's ChatGPT/Codex allowance. Mathnuscripts will not receive the user's ChatGPT password.
